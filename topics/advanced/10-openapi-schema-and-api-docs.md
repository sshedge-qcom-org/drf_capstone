## The schema
- [ ] **drf-spectacular** (de-facto OpenAPI 3 standard) and drf-yasg (older OpenAPI 2)
- [ ] built-in coreapi/CoreJSON schema is **deprecated / removed** from DRF core
- [ ] `@extend_schema` / `@extend_schema_view` to customize operations
- [ ] `AutoSchema` and `SchemaGenerator`

## Docs UIs
- [ ] Swagger UI and ReDoc render the **same** OpenAPI schema (`SpectacularSwaggerView` vs `SpectacularRedocView`)
- [ ] schema settings (`SPECTACULAR_SETTINGS`): servers, auth schemes, examples, versioned schemas
